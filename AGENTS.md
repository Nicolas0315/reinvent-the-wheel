# Agent instructions

This repository implements Myers diff in `rewheel/` and checks it with
`test_rewheel.py`. Follow the user's active instructions and the shared
development baseline in addition to this file.

## Work and verification

- Make changes on a branch and use a pull request for `main`.
- Run `python3 test_rewheel.py` after changes to the diff implementation.
- Keep the diff reconstruction and minimality checks passing. Preserve the
  public output format unless the requested change explicitly alters it.
- Keep examples and generated output free of credentials and personal data.
